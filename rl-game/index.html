The Feed

A small reinforcement-learning game. Each round, pick one of four posts to show a simulated user. Clicks earn points, but outrage quietly erodes the user's trust.

1. Play the game

20 rounds. Use the buttons or the arrow keys (← news, ↑ sports, → outrage, ↓ local). The click chances are fixed; trust is hidden, but you can see whether it is high, medium or low.

2. The reward function

These numbers are what the agent is trying to maximize. Changing them changes what it learns. (Press Reset agent after a change so it starts fresh.)

3. The Q-learning agent

Tabular Q-learning: explore at random 20% of the time (ε = 0.2), learning rate α = 0.2, discount γ = 0.95, all Q-values start at 0, ties broken at random.

Q-table: the agent's estimate of future points for each post in each state. The highlighted cell is what it would pick.

Each point averages 50 training games (with exploration on). The two measures have different units, so they get separate panels on a shared x-axis. Simulated data from this page only; it describes the agent's behavior here, not real users.
